# Massive MIMO Channel Capacity Analysis Using MATLAB

## Overview

This project demonstrates the analysis of **Massive MIMO Channel Capacity** using **MATLAB**. The simulation evaluates the relationship between **Signal-to-Noise Ratio (SNR)**, **Channel Capacity**, and **Antenna Array Gain**. It illustrates how increasing the SNR and the number of antenna elements improves the channel capacity and overall performance of modern wireless communication systems.

---

## Objectives

1. **To analyze the channel capacity** of a Massive MIMO system under different SNR values.

2. **To evaluate the relationship between SNR and channel capacity** using Shannon's capacity theorem.

3. **To study the effect of antenna array size** on antenna gain in Massive MIMO systems.

## Simulation Parameters

| Parameter | Value |
|-----------|-------|
| SNR Range | 0 dB to 30 dB (Step: 5 dB) |
| Channel Capacity Formula | C = log₂(1 + SNR) |
| Antenna Array Sizes | 4, 8, 16, 32, 64 |
| Antenna Gain Formula | 10 × log₁₀(N) dB |

## Result

The simulation successfully demonstrates that the channel capacity increases with increasing SNR, following Shannon's capacity theorem. It also shows that antenna gain improves as the number of antenna elements increases, highlighting the advantages of Massive MIMO in enhancing system capacity and communication performance.
