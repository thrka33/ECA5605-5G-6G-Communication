# V2X Communication Performance Analysis Using MATLAB

## Overview

This project demonstrates the performance analysis of **Vehicle-to-Everything (V2X) Communication** using **MATLAB**. The simulation evaluates the impact of **vehicle speed** on **end-to-end latency**, **packet delivery ratio (PDR)**, and **communication range**. The generated graphs illustrate how communication performance changes under different vehicle speeds, providing insights into the reliability of V2X communication systems used in intelligent transportation.

---

## Objectives

1. **To analyze the end-to-end latency** of V2X communication for different vehicle speeds.

2. **To evaluate the Packet Delivery Ratio (PDR)** under varying vehicle speeds.

3. **To analyze the communication range** of vehicles at different operating speeds.

## Result

The MATLAB simulation successfully demonstrates the performance characteristics of V2X communication under different vehicle speeds. The results show that **end-to-end latency decreases** as communication becomes more efficient, while the **Packet Delivery Ratio gradually decreases** at higher vehicle speeds due to increased mobility. The **communication range also reduces** with increasing speed, highlighting the challenges of maintaining reliable wireless links in high-speed vehicular environments.
