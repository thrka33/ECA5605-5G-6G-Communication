# MIMO Beamforming Analysis Using MATLAB

## Overview

This project demonstrates the analysis of **MIMO (Multiple Input Multiple Output) Beamforming** using **MATLAB**. The simulation evaluates the relationship between **steering angle**, **array gain**, and **beam direction error**. It illustrates how beamforming directs the transmitted signal toward the desired user while improving signal quality and reducing interference in modern wireless communication systems.

---

## Objectives

1. **To analyze the steering angle** in a MIMO beamforming system.

2. **To evaluate the array gain** for different steering directions.

3. **To measure the beam direction error** between the desired and actual beam directions.

---

## Features

- Steering angle visualization using a polar plot.
- Array gain analysis for different beam directions.
- Beam direction error calculation.
- MATLAB-based graphical representation of MIMO beamforming.
- Performance evaluation of beam steering accuracy.

---

## Output

The MATLAB simulation generates:

- Steering Angle Variation (Polar Plot)
- Array Gain vs Steering Angle (Bar Graph)
- Beam Direction Error vs Desired Steering Angle (Line Graph)

---

## Result

The simulation successfully demonstrates the operation of MIMO beamforming. The array gain reaches its maximum near the broadside direction (0°), while the beam direction error remains small for all steering angles, indicating accurate beam steering and improved signal transmission.
