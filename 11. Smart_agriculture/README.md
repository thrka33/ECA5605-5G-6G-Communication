# IoT Smart Agriculture – Soil Moisture Monitoring Using MATLAB

## Overview

This project demonstrates the analysis of an **IoT-based Smart Agriculture System** using **MATLAB**. The simulation monitors **soil moisture levels**, determines the **soil condition (Wet/Dry)**, controls the **water pump automatically**, and evaluates **irrigation efficiency**. It illustrates how IoT technology can improve water management and automate irrigation in modern agriculture.

---

## Objectives

1. **To monitor soil moisture levels** over different time intervals.

2. **To determine the soil condition** (Wet/Dry) based on a predefined moisture threshold.

3. **To automatically control the irrigation pump** according to soil moisture levels and evaluate irrigation efficiency.

## Simulation Parameters

| Parameter          | Value                                  |
| ------------------ | -------------------------------------- |
| Time Duration      | 1–10 Hours                             |
| Soil Moisture (%)  | 30, 35, 28, 25, 20, 18, 22, 30, 40, 45 |
| Moisture Threshold | 40%                                    |
| Soil Condition     | Wet (≥40%), Dry (<40%)                 |
| Pump Status        | ON (Dry), OFF (Wet)                    |

## Result

The MATLAB simulation successfully demonstrates an IoT-based smart irrigation system. The results show that the water pump automatically turns **ON** when soil moisture falls below the threshold and turns **OFF** when sufficient moisture is available. The irrigation efficiency graph provides insight into the effectiveness of water usage, making the system suitable for smart farming applications.
